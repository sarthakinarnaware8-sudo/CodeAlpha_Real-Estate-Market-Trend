# Real Estate Market Trends

## Project Overview

This project is an interactive Real Estate Market Trends Dashboard developed using Power BI. It provides insights into property pricing, house features, geographic distributions, and overall real estate market metrics.

---

## Objectives

* Analyze overall real estate market metrics
* Evaluate property pricing across different bedroom counts
* Examine house price distribution patterns
* Compare property prices based on property condition
* Visualize geographic house price distribution on a map
* Build an interactive dashboard using Power BI

---

## Dashboard Features

* Total Houses
* Average Price
* Max Price
* Average Area
* Price by Bedrooms
* Price Distribution
* Average Price by Condition
* House Price Map
* Interactive Slicers (Bedrooms, Bathrooms, Grade, Waterfront)

---

## Tools Used

* Power BI Desktop
* Microsoft Excel

---

## Dataset

Real estate market dataset containing property records with pricing, location, and structural attributes.
